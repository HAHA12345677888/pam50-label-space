## 9. 方法学说明

### 数据预处理
- mRNA: rank normalization → Z-score (within-platform)
- 临床特征: one-hot encoding (69维)
- 甲基化: top 232 probes by variance
- 突变: 二值化 (presence/absence)

### 跨平台对齐
- METABRIC: 微阵列 log2 表达值 → rank → Z-score
- TCGA: RNA-seq RSEM → log2(x+1) → rank → Z-score
- 412 个基因完全匹配 (gene symbol → Entrez Gene ID via cBioPortal)

### 模型
- Logistic Regression, C=0.01, max_iter=4000
- 多分类策略: multinomial (softmax)
- 评估: accuracy, macro F1, C-Index, log-rank test

### 生存分析
- Cox proportional hazards (predicted probabilities as covariates, LumA=reference)
- Risk score: 1 - P(LumA)
- Penalizer=0.1 (l2 regularization)
